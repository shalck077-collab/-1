# تطبيق إدارة فواتير الكهرباء والمياه

## 📱 تطبيق ويب تقدمي (PWA) احترافي

تطبيق كامل للعمل بدون إنترنت لإدارة وحساب فواتير الكهرباء والمياه مع تصميم حديث وقاعدة بيانات محلية وتقارير احترافية.

## ✨ المميزات

- ✅ يعمل بدون إنترنت (Offline First)
- ✅ قابل للتثبيت كتطبيق حقيقي
- ✅ قاعدة بيانات محلية (IndexedDB)
- ✅ لوحة تحكم احترافية (Dashboard)
- ✅ إدارة سجلات الكهرباء والمياه
- ✅ تقارير PDF و Excel
- ✅ رسوم بيانية وإحصائيات
- ✅ نسخ احتياطي واستعادة
- ✅ حماية بكلمة مرور
- ✅ وضع ليلي/نهاري
- ✅ دعم اللغة العربية RTL

## 🏗️ هيكل المشروع

```
.
├── index.html              # صفحة الدخول
├── app.html                # صفحة التطبيق الرئيسية
├── manifest.json           # ملف PWA
├── service-worker.js       # خادم الخدمة
├── css/
│   ├── styles.css          # الأنماط الأساسية
│   ├── dashboard.css       # أنماط لوحة التحكم
│   ├── forms.css           # أنماط النماذج
│   └── responsive.css      # الاستجابة
├── js/
│   ├── db.js               # قاعدة البيانات
│   ├── app.js              # التطبيق الرئيسي
│   ├── auth.js             # المصادقة
│   ├── dashboard.js        # لوحة التحكم
│   ├── bills.js            # إدارة الفواتير
│   ├── reports.js          # التقارير
│   ├── charts.js           # الرسوم البيانية
│   ├── backup.js           # النسخ الاحتياطي
│   ├── utils.js            # دوال مساعدة
│   └── pwa.js              # إدارة PWA
├── assets/
│   ├── icons/              # الأيقونات
│   ├── logo.png            # الشعار
│   └── splash.png          # صورة البداية
└── lib/
    └── chart.min.js        # مكتبة الرسوم البيانية
```

## 🚀 البدء السريع

1. افتح `index.html` في المتصفح
2. أنشئ كلمة مرور
3. ابدأ بإضافة السجلات
4. اضغط على تثبيت التطبيق (PWA)

## 📋 المتطلبات

- متصفح حديث يدعم:

  - IndexedDB
  - PWA
  - ES6+
