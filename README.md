# نظام المحاسبة المتكامل - النسخة 3.0 (مع دعم المزامنة السحابية)

## 📋 نظرة عامة

نظام محاسبي متقدم يعمل **بدون إنترنت** (Offline-First) مع إمكانية **الربط بالسحابة** للمزامنة الآمنة. النسخة المحلية هي دائماً المرجع الأساسي.

---

## ✨ الميزات الرئيسية

### 1. **العمل بدون إنترنت (Offline-First)**
- ✅ يعمل بكفاءة كاملة بدون اتصال إنترنت
- ✅ تخزين محلي آمن باستخدام `localStorage` و `IndexedDB`
- ✅ تطبيق ويب تقدمي (PWA) قابل للتثبيت على الهاتف

### 2. **المزامنة السحابية**
- 📤 رفع البيانات للسحابة يدوياً
- 📥 تحميل البيانات من السحابة (مع تحذير)
- 🔄 مزامنة تلقائية اختيارية عند توفر الإنترنت
- 🔒 النسخة المحلية دائماً هي المرجع الأساسي

### 3. **إدارة العماير**
- إضافة وتعديل العماير
- تسجيل المسلمات والمبالغ
- تقارير مفصلة حسب العمارة
- حالة الدفع والأرصدة

### 4. **إدارة العمال**
- تسجيل العمال والرواتب
- تتبع المستحقات والمدفوعات
- حساب الأرصدة المتبقية
- تقارير الأداء

### 5. **إدارة الشراكة**
- تسجيل عمليات الشراكة بين يحيى وصدام
- حساب الأرصدة والتوزيع
- ملخص تصفية الحساب
- تقارير شاملة

### 6. **لوحة التحكم المتقدمة**
- 📊 رسوم بيانية تفاعلية
- 📈 إحصائيات سريعة
- 🎯 ملخصات مالية
- 🔍 بحث سريع وفلترة

### 7. **الإعدادات والتخصيص**
- 🎨 تخصيص الألوان
- 🎭 تبديل الوضع الليلي
- 🔐 حماية بكلمة مرور
- 🎯 تخصيص الأيقونات

## 🚀 البدء السريع

### 1. التثبيت
```bash
# فك ضغط الملف
unzip accounting_app_online_ready.zip

# افتح index.html في المتصفح
# أو استضفه على خادم ويب
```

### 2. التثبيت كتطبيق (PWA)
- **على الهاتف**: اضغط على القائمة > "إضافة إلى الشاشة الرئيسية"
- **على الحاسوب**: اضغط على أيقونة التثبيت في شريط العنوان

### 3. الاستخدام الأساسي
```
1. الرئيسية: عرض الإحصائيات والرسوم البيانية
2. العماير: إدارة العماير والمسلمات
3. العمال: تسجيل الرواتب والمستحقات
4. الشراكة: تسجيل عمليات الشراكة
5. الإعدادات: تخصيص وحماية البيانات
```

## 🐛 استكشاف الأخطاء

### المشكلة: البيانات لا تظهر
**الحل:**
1. تحقق من أن المتصفح يدعم `localStorage`
2. تأكد من عدم تفعيل "الوضع الخاص" (Private Mode)
3. امسح ذاكرة التخزين المؤقتة وأعد تحميل الصفحة

### المشكلة: المزامنة لا تعمل
**الحل:**
1. تحقق من اتصالك بالإنترنت
2. افتح وحدة التحكم (F12) وابحث عن الأخطاء
3. تأكد من صحة بيانات الاتصال بالسحابة

### المشكلة: التطبيق بطيء
**الحل:**
1. امسح البيانات القديمة (مسح البيانات)
2. أعد تحميل الصفحة
3. تحقق من حجم البيانات المخزنة
